## Binding steps (Take a MyArm C650 robotic arm as an example)

### 1. Connect the machine to the computer through the serial port

### 2. Check the serial port number of the robot arm
Run the `ls /dev/tty*` command to view the serial port number. For example, the serial port number is `/dev/ttyUSB0`

### 3. This command is used to view details about the serial port
`udevadm info --name=/dev/ttyUSB0 --attribute-walk`

### 4. Find and record the data corresponding to serial, idVendor and idProduct that appear for the first time
<img src="../../../resources/4-FunctionsAndApplications/6-SDKDevelopment/5.4-DevelopmentBasedOnCommunicationProtocolPackage/tracer_use/USB-1.jpg" alt="7.1.1-1" style="zoom:100%;" />  

### 5. Create a file in the directory `/etc/udev/rules.d/` with a name you can customize, such as `99-mc-serial-ports.rules`, and add the following:
```
KERNEL=="ttyUSB[0-255]*", SUBSYSTEM=="tty", SUBSYSTEMS=="usb", ATTRS{idVendor}=="10c4", ATTRS{idProduct}=="ea60", ATTRS{serial}=="023EE1FB", MODE:="0777", GROUP:="dialout", SYMLINK+="c650_left"
```
Among them, '10c4' and 'ea60' correspond to idVendor and idProduct, '023EE1FB' corresponds to serial, 'c650_left' is a user-defined serial port name, which can be customized according to needs.

### 6. Reload the udev rule
`sudo udevadm control --reload`

### 7. Reinsert the serial port device to make the udev rule take effect
`sudo udevadm trigger`

### 8. Check whether the serial port device is bound successfully. (After the serial port device is fixed,/dev/c650_left indicates the serial port number of the device and points to /dev/ttyUSB0.)
`ll /dev/c650_left`
